# 설정 전체 설명

[한국어 목차](README.md) · [English](../en/configuration.md)

반동을 바꾸려면 무기의 `RecoilSpell`, 조준 중 이동 속도를 바꾸려면 `AimSpell`, 명중 피해를 바꾸려면 `HitSpell` 아래에 속성을 적습니다. 처음 설치한다면 [설치와 첫 발사](getting-started.md)부터 따라 하세요.

## 예시로 읽는 설정

`plugins/MagicSpells/spells-recoil.yml`에 다음 주문을 작성하세요. 첫 줄은 주문 이름이고, 두 칸 들여쓴 줄은 이 주문에 적용할 속성입니다. 표의 **기본값**은 해당 줄을 생략했을 때 적용되는 값입니다.

```yaml
Wiki_Recoil:
  spell-class: dev.magicrecoil.spells.RecoilSpell  # 이 주문을 시점 반동에 연결
  pattern: vertical  # 위로만 움직이는 패턴
  recoil: 2          # 가만히 서서 쏘면 한 발에 2° 상승
  growth: 0          # 연사해도 한 발의 세기는 일정
  recoil-steps: 2    # 한 발의 움직임을 두 틱에 나누어 표시
```

플레이어가 접속한 상태에서 `/ms reload` 후 서버 콘솔에 `ms cast as PlayerName Wiki_Recoil`을 입력하세요. `PlayerName`은 접속한 플레이어 이름입니다. 정면을 보고 멈춰 선 상태에서 `recoil`만 `1`로 낮춰 다시 적용하면 시점이 절반만큼 올라갑니다.

**단위 읽기** — `°`는 시점이 움직이는 각도입니다. 배율 `1`은 원래 크기, `0.5`는 절반입니다. `400ms`는 0.4초이며, 20 TPS에서 서버 1틱은 약 0.05초입니다. 숫자와 `true`·`false`는 따옴표 없이 적습니다. 범위를 벗어나거나 숫자 자리에 수식을 쓰면 콘솔에 주문 이름과 오류가 표시됩니다.

## 기본 옵션

| 옵션 | 기본값 | 단위·범위 | 의미 |
| --- | --- | --- | --- |
| `recoil` | `2.5` | 도(°), 0..45 | 한 발의 기본 세기. 값을 낮추면 같은 패턴에서 시점이 덜 움직이며, 0이면 반동이 사라집니다. |
| `vertical` | `1.0` | 배율, 0..10 | 패턴의 위아래 움직임을 키우거나 줄입니다. 0이면 수직 반동이 사라집니다. |
| `horizontal` | `0.4` | 배율, 0..10 | 패턴의 좌우 움직임을 키우거나 줄입니다. 기본 설정의 `vertical` 패턴은 좌우 움직임이 0이어서 이 값만 높여도 옆으로 움직이지 않습니다. |
| `moving-recoil-multiplier` | `1.5` | 배율, 1..10 | 발사 시 이동 방향 입력이 있으면 양쪽 축에 곱함. 이동 중에도 기본 반동을 쓰려면 `1.0`으로 설정 |
| `smoothness` | `0.5` | 0..1 | 한 발의 반동을 몇 틱에 나눠 보여 줄지 정합니다. 0은 1틱, 0.5는 3틱, 1은 5틱입니다. |
| `growth` | `0.08` | 발당 증가 비율, 0..1 | 연사 중 한 발마다 기본 세기의 몇 배를 더할지 정합니다. 기본값이면 첫 세 발은 기본 세기의 100%, 108%, 116%입니다. |
| `reset-delay` | `400` | ms, 정수 50..60000 | 이 시간 이상 쉬면 다음 발이 패턴의 첫 발로 돌아갑니다. 값을 키우면 더 긴 간격으로 쏴도 연사가 이어집니다. |
| `pattern` | `valorant` | `valorant`, `vertical`, `horizontal`, `random`, `custom` | 발마다 시점이 움직이는 방향을 고릅니다. 다섯 가지 움직임은 [패턴 정의](#패턴-정의)에서 비교하세요. 대소문자를 구분하지 않으며 `horizental`도 `horizontal`로 읽습니다. |
| `auto-return` | `false` | `true` / `false` | 켜면 사격을 멈추고 남은 반동이 끝난 뒤, 반동으로 움직인 만큼 시점을 반대 방향으로 돌립니다. |

첫 발은 `n = 0`입니다. 여기서 발사 횟수는 마우스 클릭 횟수가 아니라 승인된 반동 주문 호출 횟수입니다. 카운터는 숫자 안정성을 위해 1,000,000에서 멈추며 일반적으로 그 전에 `max-recoil` 제한에 도달합니다.

초기화 간격은 단조 증가하는 실제 시간으로 계산하고, 애니메이션은 서버 틱으로 처리합니다. 20 TPS에서 3틱은 약 150ms이며 첫 적용은 다음 스케줄러 틱입니다. TPS가 낮으면 더 오래 걸립니다. 초기화 간격을 넘긴 뒤 다시 쏘면 기존 잔여 반동을 취소하고 첫 발부터 시작합니다.

## 고급 옵션

| 옵션 | 기본값 | 단위·범위 | 의미 |
| --- | --- | --- | --- |
| `vertical-min` | `0.0` | 계수, -10..10 | 위아래 움직임의 최솟값입니다. 아래로 움직이는 패턴 점을 쓰려면 이 값도 음수로 낮추세요. |
| `vertical-max` | `2.0` | 계수, -10..10 | 위쪽으로 움직일 수 있는 최대 크기입니다. `random`에서 수직 최솟값과 같게 두면 수직 계수가 고정됩니다. |
| `horizontal-min` | `-1.0` | 계수, -10..10 | 좌우 움직임의 최솟값입니다. 음수 쪽 범위를 넓히면 더 큰 왼쪽 반동을 허용합니다. |
| `horizontal-max` | `1.0` | 계수, -10..10 | 좌우 움직임의 최댓값입니다. 양수 쪽 범위를 넓히면 더 큰 오른쪽 반동을 허용합니다. |
| `horizontal-bias` | `0.0` | 계수, -10..10 | 매 발의 수평 계수에 더합니다. 양수면 오른쪽, 음수면 왼쪽으로 치우칩니다. |
| `valorant-max-rise` | `15.0` | 도(°), 0..90 | valorant 연사의 누적 위쪽 반동 상한. 발 수 고정이 아니며 다른 패턴에는 적용 안 됨 |
| `max-recoil` | `8.0` | 도(°), 0.01..45 | 한 발의 위아래·좌우 움직임을 합친 각도의 상한입니다. 대각선 반동이 상한을 넘으면 두 방향을 함께 줄입니다. |
| `pattern-randomness` | `0.0` | 계수, 0..1 | 패턴에 매 발 무작위 변화를 더합니다. 0.2면 적용되는 축의 계수에 -0.2부터 +0.2 사이 값을 더합니다. |
| `recoil-steps` | 자동 계산 | 틱, 정수 1..20 | 한 발의 움직임을 나눌 틱 수입니다. 직접 쓰면 `smoothness`보다 우선합니다. |
| `custom-pattern` | 빈 목록 | `custom`에서 1..1024개 | 목록 한 줄이 한 발입니다. 각 줄에 위아래(`vertical`)와 좌우(`horizontal`) 계수를 모두 적습니다. 각각 -10..10입니다. |
| `pattern-repeat` | `loop` | `loop`, `hold`, `stop` | 사용자 패턴을 다 썼을 때 처음부터 반복(`loop`), 마지막 점 유지(`hold`), 이후 반동을 멈춤(`stop`) 중 하나를 선택합니다. |

각 min은 max보다 클 수 없습니다. min/max는 **각도가 아니라 배율 적용 전 계수**이며 플레이어의 절대 시야 제한도 아닙니다. 수직 양수는 위쪽, 수평 양수는 오른쪽입니다. 아래쪽 반동을 원하면 음수 수직 계수와 음수 `vertical-min`을 설정합니다.

`recoil-steps`가 있으면 분할 수 결정에 `smoothness`를 사용하지 않습니다. 모든 반동은 앞부분이 강하고 점점 약해지는 동일한 가중치 곡선을 사용합니다. smoothness는 스프링 상수나 클라이언트 FPS가 아닙니다.

## 조준 속성

아래 속성은 조준을 시작하는 `AimSpell`에 적습니다. `recoil-spells`에는 같은 파일 또는 다른 주문 파일에 정의한 반동 주문의 **이름**을 넣습니다. 예를 들어 위 주문에 조준을 연결하려면 `recoil-spells: [Wiki_Recoil]`로 적으세요. [조준과 해제 주문 YAML 예제](../../examples/aim-integration.yml)

| 속성 | 기본값 · 허용값 | 조준 중 효과 |
| --- | --- | --- |
| `enabled` | `true` · true/false | `false`이면 이 주문으로 조준을 시작할 수 없습니다. |
| `recoil-spells` | `[]` · 주문 이름 목록 | 조준 반동 배율을 받을 주문입니다. 조준을 켜려면 하나 이상 지정하세요. |
| `recoil-multiplier` | `0.5` (SLOWNESS: 1) · 0..1 | 목록에 있는 반동 주문의 세기를 조절합니다. 0.5면 절반, 0이면 조준 중 반동이 사라집니다. |
| `movement-speed-multiplier` | `0.65` (SLOWNESS: 1) · 0.01..1 | 조준 중 이동 속도에 곱합니다. 0.65는 평소의 65%, 1은 평소 속도입니다. |
| `toggle` | `true` · true/false | 켜면 같은 주문을 다시 사용할 때 조준이 풀립니다. 끄면 다시 사용해도 유지되므로 해제 시점에 `StopAimSpell` 등을 연결하세요. |
| `cancel-on-item-swap` | `true` · true/false | 켜면 손에 든 단축바 슬롯을 바꿀 때 조준을 끝냅니다. |
| `cancel-on-hand-swap` | `true` · true/false | 켜면 주 손과 보조 손의 아이템을 맞바꿀 때 조준을 끝냅니다. |
| `stop-on-spells` | `[]` · 주문 이름 목록 | 재장전처럼 지정한 주문의 시도를 감지하면 조준을 끝냅니다. |
| `stop-on-buff-end` | `[]` · 버프 이름 목록 | 플레이어에게 걸린 지정 버프가 끝날 때 조준을 해제합니다. |
| `cancel-on-death` | `true` 고정 | 사망하면 조준이 풀립니다. 생략해도 적용됩니다. |
| `cancel-on-logout` | `true` 고정 | 접속을 종료하면 조준이 풀립니다. 생략해도 적용됩니다. |

교체로 조준을 해제하는 옵션을 끄면 원래 슬롯과 아이템이 다시 일치할 때 조준 배율이 돌아옵니다. 각 이름 목록은 최대 128개입니다. 조준 키는 기존 MagicSpells 입력 설정에서 연결합니다. [조준 연동 방법](integration.md#선택적-조준-상태)

## 정확한 적용 순서

1. 다른 반동 주문으로 바뀌었거나 초기화 간격이 지났으면 세션을 초기화하고 패턴의 `n`번째 값을 선택합니다.
2. random은 설정한 min/max에서 수직·수평 값을 독립적으로 추출합니다. 나머지 패턴은 아래 규칙으로 계산합니다.
3. `horizontal` 패턴은 수직 반동을 0으로 고정합니다. 다른 패턴에서는 수직에 잡음을 더합니다. 수평은 `vertical` 이외의 패턴에만 잡음을 더하고, 모든 패턴에 `horizontal-bias`를 적용합니다.
4. 각 계수를 min/max 범위로 제한합니다.
5. `recoil × (1 + growth × n)`과 각 축 배율을 곱합니다. 이동 방향을 입력 중이면 양쪽 축에 `moving-recoil-multiplier`를 곱합니다. 수직 값의 부호를 반전하여 Minecraft pitch로 바꿉니다.
6. valorant이면 세션의 `valorant-max-rise`를 넘지 않도록 이번 발의 위쪽 pitch를 줄입니다. 마우스 입력과 독립적인 상승 예산입니다.
7. 남은 yaw/pitch 합성 길이가 max-recoil보다 크면 두 축을 같은 비율로 줄입니다. 제한 후 위쪽 적용 예정량을 상승 예산에서 차감합니다. 조준 배율을 곱한 뒤 `s`틱에 가중치 `(s-i) / (s(s+1)/2)`로 나눕니다. 3틱이면 `1/2, 1/3, 1/6`입니다.
8. 고정 길이 버퍼의 같은 틱에 더합니다. 한 틱의 합성 길이는 45°로 제한하며, 비정상적으로 많은 동시 발사의 초과량은 버립니다.
9. 메인 스레드에서 서버의 현재 pitch를 기준으로 `-90°..+90°`를 넘지 않도록 제한하고 상대 회전을 한 번 적용합니다. 시작 시점의 절대 각도를 저장해서 덮어쓰지 않습니다.

기본값에서 첫 발 `recoil: 2.5`는 yaw 0°, pitch -2.5°이며, 세 틱에 약 -1.25°, -0.8333°, -0.4167°로 나뉩니다. 둘째 발의 강도는 분할 전 2.7°입니다. 그 사이에도 사용자는 마우스를 움직일 수 있습니다.

## 패턴 정의

- `valorant`: 기본 수직 계수 1이며 세션에서 `valorant-max-rise` 각도에 도달하면 추가 상승을 중지합니다. 수평은 중앙 기준 sin 목표 위치의 차이로 계산합니다. **기본 첫 4발은 수평 0, 이후 중앙의 좌우 양쪽으로 움직입니다.** 실제 게임 데이터가 아닌 독자적인 근사입니다. 상세 계산과 공개 자료의 구분은 [반동 로직](recoil-logic.md#내장-valorant의-상한과-좌우-중심)에 있습니다.
- `vertical`: `(수직 1, 수평 0)`. 수평 잡음은 없지만 명시적인 bias나 min/max 설정은 수평 변화를 만들 수 있습니다.
- `horizontal`은 첫 발부터 연사의 중심을 기준으로 좌우로 움직입니다. 수직 설정값과 관계없이 수직 반동은 0입니다.
- `random`: 각 축의 범위에서 균일하게 추출한 뒤 동일한 잡음·bias·제한 과정을 적용합니다. min=max도 가능합니다.
- `custom`: 한 발마다 한 점을 사용합니다. `loop`는 처음부터 반복, `hold`는 마지막 점 유지, `stop`은 끝난 뒤 무반동입니다. 반복되어도 연사 증가율은 초기화하지 않습니다.

`horizontal`은 패턴 계수에 곱하는 배율입니다. 기본 bias·범위의 `vertical`에서는 수평 계수가 0이라 배율만 올려도 움직이지 않습니다. 첫 발부터 random 수평을 주면서 수직을 고정하려면 `pattern: random`, `vertical-min: 1`, `vertical-max: 1`과 원하는 수평 범위·배율을 함께 지정합니다. 계산식, 0.5도/±0.75도 예시, 초기화와 복귀 규칙은 [반동 로직 상세](recoil-logic.md)에 정리했습니다.

```yaml
Recoil_Custom:
  spell-class: "dev.magicrecoil.spells.RecoilSpell"
  recoil: 2.0
  pattern: custom
  pattern-repeat: hold
  custom-pattern:
    - {vertical: 1.0, horizontal: 0.0}
    - {vertical: 1.2, horizontal: 0.4}
    - {vertical: 1.0, horizontal: -0.5}
```

## 연동 옵션

| 옵션 | 기본값 | 의미 |
| --- | --- | --- |
| `require-success-of` | 빈 문자열 | 바로 앞 발사체 주문의 내부 이름. 같은 틱의 성공 기록을 한 번 소비. 비어 있으면 검사 안 함 |
| `stop-on-spells` | `[]` | 해당 주문의 **시도**가 발생하면 연결된 활성 반동 중지. 실패한 재장전 시도도 중지됨 |
| `stop-on-buff-end` | `[]` | 플레이어에게 적용된 해당 버프가 끝나면 연결된 활성 반동 중지 |

이름은 대소문자를 구분하지 않으며 목록에는 최대 128개의 비어 있지 않은 문자열을 넣습니다. 없는 주문 참조는 경고를 출력합니다. 성공 이벤트를 받을 수 없는 direct/delayed 호출은 [연동 문서](integration.md)를 참고하세요.

설정된 중지 이벤트는 해당 플레이어의 성공 기록도 지우고 같은 틱의 이후 반동을 모두 거부합니다. 발사체 → 재장전 시작 → 반동 순서에서도 반동이 실행되지 않도록 한 것입니다. 다음 틱부터의 재장전 상태를 대신 관리하지는 않으므로 원래 총기 로직이 발사를 막아야 합니다.

## 선택적 자동 복귀

`auto-return: true`는 초기화 간격이 지나고 남은 반동이 끝난 뒤 실제 적용한 상대 변화량의 합을 반대로 적용합니다. 합은 축마다 ±90°로 제한하며, 시점 한계 때문에 버린 pitch는 기록하지 않습니다. 복귀에도 같은 분할 틱 수를 사용합니다. 새 발사, 무기 교체, 재장전, 사망, 로그아웃, reset은 해당 복귀를 취소합니다.

사용자가 마우스로 얼마나 제어했는지는 알 수 없으므로 조준을 과하게 되돌릴 수 있습니다. 요청한 기본 FPS 동작에는 `false`를 유지하세요.

## 선택 기능 AimSpell 설정

AimSpell과 StopAimSpell의 [전체 설정·기본값·허용 범위](aim-and-input.md#바인딩과-전체-설정)를 참고하세요. 기존 RecoilSpell에는 새 YAML이 필요 없습니다. AimSpell의 `recoil-spells`로 해당 총기에만 반동 감소를 적용합니다. 정확한 좌클릭 HOLD와 광학 배율은 제외하고 선택 FOV 효과와 우클릭 입력 모드는 별도로 설정합니다.

## 자동 사격과 선택 확대 설정

AutoFireSpell / StopAutoFireSpell의 전체 설정은 [우클릭 자동 사격](aim-and-input.md#우클릭-자동-사격)을 참고하세요. 기본 BUFFERED_CLICK, 선택 NATIVE_USE, 해제를 추정하는 REPEATED_CLICK을 구분합니다. AimSpell 확대는 설정을 생략하면 꺼져 있으며 SLOWNESS·FOV_EFFECT 모드를 명시하여 켭니다. 정확한 좌클릭 HOLD와 광학 배율 zoom.level은 지원하지 않습니다.

기본 파이먼 예제는 BUFFERED_CLICK과 SLOWNESS 조준을 사용하며 recoil-multiplier·movement-speed-multiplier 모두 1.0입니다. Slowness 자체의 이동 감속은 적용됩니다. FOV_EFFECT는 대안으로 유지합니다.
