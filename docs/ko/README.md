## 처음 사용한다면

1. **[설치와 첫 발사](getting-started.md)** — 지원 환경과 최소 주문부터 확인합니다.
2. **[반동 로직](recoil-logic.md)** — 수직·수평 배율과 패턴을 이해합니다.
3. **[기존 총기 연결](integration.md)** — 발사 성공·탄약·재장전 조건을 연결합니다.
4. **[실제 테스트](testing.md)** — 마우스 보정, 연사, 무기 교체를 검수합니다.

반동 주문 실행 성공만으로 탄약 검사나 재장전 처리가 완성되지는 않습니다. 기존 총기 로직을 유지하고 실제 발사 분기를 확인하세요.

## 운영자와 개발자 읽기 순서

**운영자:** 빠른 시작 → 반동 로직 → 연동 → 테스트. 숫자를 조정할 때는 설정 표를, 문제가 생기면 증상별 문서를 엽니다.

**개발자:** 반동 로직 → 구조 → 개발 → 테스트. 구현 변경 시 영어·한국어 문서와 검증 범위를 함께 갱신합니다.

## 문서 사용 방법

각 페이지 상단의 목차는 해당 절로 이동합니다. 상단의 언어 링크는 같은 주제의 다른 언어 문서를 엽니다. 하단의 이전·다음 링크는 추천 읽기 순서를 따릅니다.

저장소의 `docs/`를 문서 원본으로 사용하며 GitHub Wiki에도 같은 내용을 게시합니다. 편집과 목차·Wiki 재생성 방법은 [문서 관리](development.md#문서와-wiki-관리)에 있습니다.
